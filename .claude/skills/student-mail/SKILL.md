# 수강생 안내 메일

자동 발송 메일(`docs/20.working/season2/apps-script-mailer.gs`)이 처리하지 못하는
**개별 응대**를 담당한다. 사람마다 금액이 다르거나, 입금 확인처럼 사람이 눈으로 봐야
하는 건이라 자동화하지 않는다.

## 절대 규칙

**메일을 직접 보내지 않는다. 임시보관함 초안까지만 만들고 멈춘다.**
발송은 사용자가 직접 한다. 사용자가 "보내줘"라고 명시하면 그때만 보낸다.

## 두 가지 메일

### A. 신청 확인 후 — 결제 안내 (할인 반영)

자동 발송된 신청 완료 메일에 수강생이 "할인가로 입금해도 되나요?" 하고 답장했을 때.

1. `search_threads` 로 해당 수강생 스레드를 찾는다 (이름 또는 메일 주소로).
2. `get_thread` 로 자동 발송 메일의 **이름·금액·계좌·일정**을 확인한다. 지어내지 않는다.
3. 스레드의 **마지막 메시지 id**에 `replyToMessageId` 를 걸어 `create_draft`.

담을 내용:
- 신청 감사 인사
- 수강료 — 정식가에 취소선, 할인가를 크게. "말씀하신 대로 N만원으로 입금해 주시면 됩니다"
- 입금계좌 + 입금자명 안내 + 현금영수증 안내
- 카톡방 링크. **참여 코드는 넣지 않는다** (입금 전에는 알려주지 않는다)
- 개강일·진행 방식
- 구글 플레이 개발자 계정($25) 미리 등록 안내

### B. 입금 확인 후 — 카톡방 초대

입금 내역을 확인한 뒤. 금액과 입금자명을 사용자에게 받아서 쓴다.

담을 내용:
- "입금 확인했습니다" + 입금액·수강 등록 완료 (초록 박스)
- 카톡방 링크 + **참여 코드** — `CONFIG.KAKAO_CODE` 값을 그때 읽어서 쓴다
- 개강일·진행 방식
- 구글 플레이 개발자 계정 안내

## 메일 HTML 작성 규칙

자동 발송 메일과 **같은 모양**으로 만든다. 톤이 다르면 수강생이 위화감을 느낀다.

- **완전한 HTML 문서로 만든다.** `<!doctype html><html><head><meta charset="utf-8">…<body style="background:#f4f4f5">`
  부터 시작한다. `<div>` 조각으로만 보내면 Gmail이 `background` 를 통째로 무시해
  노란 버튼도 색 박스도 전부 흰 바탕으로 나온다. (실제로 겪음)
- **색이 들어가는 박스는 `<table bgcolor="…">`** 로 만든다. 인라인 `background` 가
  걸러져도 `bgcolor` 속성은 살아남는다.
- **이모지는 HTML 숫자 참조**로 적는다 — `&#127881;`(🎉) `&#128172;`(💬) `&#11088;`(⭐).
- 레이아웃: `#f4f4f5` 바탕 → `max-width:600px` → 흰색 라운드 카드(`padding:32px 30px`).
  머리말은 주황색 `● 월간클로드 2기`, 꼬리말은 모집 안내 페이지 링크.

### 카톡방 버튼

이 모양을 그대로 쓴다. 라벨을 바꾸거나 "링크가 안 열리면" 같은 안내를 덧붙이지 않는다.

```html
<table cellpadding="0" cellspacing="0" border="0"><tr>
  <td bgcolor="#FEE500" style="background:#FEE500;border-radius:8px;">
    <a href="{{CONFIG.KAKAO_URL}}"
       style="display:inline-block;padding:11px 20px;color:#191600;font-size:14.5px;font-weight:700;text-decoration:none;">&#128172; 월간클로드 2기 카톡방 &rarr;</a>
  </td>
</tr></table>
```

카톡방 주소는 `CONFIG.KAKAO_URL` 의 **`open.kakao.com` 원본을 그대로** 쓴다. 자체 도메인 경유 같은 우회를
넣지 않는다.

## Gmail 도구 함정

- **`update_draft` 는 초안을 원래 스레드에서 분리시킨다.** 초안 내용을 고쳐야 하면
  수정하지 말고 `create_draft` 로 다시 만든다. 단, 삭제 권한이 없어 옛 초안이 남으니
  사용자에게 지워달라고 알린다.
- 초안 본문은 `body`(plain text)와 `htmlBody` 둘 다 채운다.

## 리디렉션 알림에 대해

방금 보낸 메일의 카톡 버튼을 누르면 Gmail이 "리디렉션 알림" 경고 페이지를 띄운다.
Gmail이 갓 도착한 메일의 링크를 검사용으로 감싸두기 때문이고, 검사가 끝나면 원본
링크로 풀린다. **메일 HTML 문제가 아니다.** 방금 보낸 테스트 메일로는 이 항목을
판정할 수 없으니, 확인하려면 하루 지난 메일의 버튼을 눌러본다.
