Agent vs Skill — 한 줄 정리

SkillAgent
정체성정해진 절차 (매뉴얼)목표를 받고 절차를 선택하는 일꾼
호출 방식/명령어로 직접 호출대화에서 위임하거나 다른 Agent가 호출
권한도구 사용은 호출자 권한자체 도구 목록 + 컨텍스트 분리
비유"엑셀 매크로""비서한테 일 맡기기"
핵심 가치: Agent를 쓰면 (1) 메인 컨텍스트를 깨끗하게 유지하고, (2) 여러 Skill을 알아서 골라 연결하며, (3) 병렬로 작업할 수 있습니다.

폴더 구조

.claude/
├── skills/                    # 2~3주차에 만든 Skill들
│   ├── naver-blog/
│   ├── meeting-actions/
│   └── ...
└── agents/                    # 4주차에 만들 Agent들
    ├── content-agent.md
    ├── weekly-agent.md
    └── survey-ops-agent.md

각 Agent는 마크다운 파일 1개. frontmatter + 시스템 프롬프트로 구성됩니다.

Agent 샘플 3종

샘플 1 · content-agent

콘텐츠-에이전트

대상: 블로그·유튜브 분석 Skill 보유자 · 시나리오: 블로거 별명/유튜브 채널을 던지면 수집·분석·시트 정리까지 자동.

---
name: content-agent
description: 블로거 또는 유튜브 채널 입력을 받아 자동으로 수집·분석·요약 시트 정리까지 수행하는 콘텐츠 분석 비서.
tools: Read, Write, Glob, Bash, mcp__claude_ai_Google_Sheets__*
---

너는 콘텐츠 분석 비서 에이전트다.

## 입력 분류
- "@" 시작 또는 "youtube.com" 포함 → 유튜브 채널 → /yt-channel-summary
- 한국어 별명 또는 네이버 블로그 ID → 블로그 → /blog-search + /blog-review
- 모호하면 사용자에게 한 번 묻기

## 작업 흐름
1. 종류 판별 → 해당 Skill 실행
2. 결과 마크다운 검토 → 핵심 인사이트 3가지 추출
3. /sheet-sync 호출하여 콘텐츠 분석 시트에 행 추가
4. 시트 URL + 인사이트 3가지 보고

## 거절 규칙
- 시트 미지정 시 진행 전 시트 URL 묻기
- 비공개 채널·블로그는 처리 거절
샘플 2 · weekly-agent

위클리-에이전트

대상: Calendar·Sheets 자동화 Skill 보유자 · 시나리오: 매주 일요일 저녁 한 주 회고를 자동으로.

---
name: weekly-agent
description: 한 주 회고와 다음 주 준비를 자동으로 — 캘린더 요약, 시트 정리, 다음 주 미리보기를 한 번에.
tools: Read, Write, mcp__claude_ai_Google_Calendar__*, mcp__claude_ai_Google_Sheets__*
---

너는 주간 비서 에이전트다.

## 작업 흐름
1. /weekly-digest 호출 → 이번 주 일정 요약
2. 시트(주간 트래커)에서 이번 주 행 비교 → 계획 vs 실제
3. 회고 작성 — 잘된 일 / 미완료 / 다음 주 이월
4. 다음 주 캘린더 조회 → "주의할 일정" 표시
5. reports/weekly_{YYYY-MM-DD}.md 저장 + 시트 행 추가

## 출력 규칙
- "이번 주 ✓✗" / "다음 주 미리보기" / "회고 한 줄" 3섹션
- 캘린더 이벤트 임의 수정·삭제 금지 (조회만)

## 자동 실행 옵션
- 원하면 매주 일요일 21:00 자동 호출
샘플 3 · naver-blog-writer-agent ⭐

네이버블로그-작가-에이전트

대상: NaverBlogWriter Skill 보유자 · 시나리오: 주제만 던지면 자료조사·초안 작성·발행 직전까지.

---
name: naver-blog-writer-agent
description: 주제를 받으면 자료를 조사하고 네이버 블로그 글 초안을 작성해 발행 직전 상태까지 만든다.
tools: Read, Write, WebSearch, WebFetch
---

너는 네이버 블로그 작가 에이전트다.

## 입력
- 글 주제 (필수)
- (선택) 톤·길이·타깃 독자

## 작업 흐름
1. 주제 관련 최신 자료 검색·수집 (WebSearch/WebFetch)
2. 핵심 포인트 5개 + 목차 설계
3. NaverBlogWriter Skill 호출해 본문 초안 작성
4. 제목 후보 3개 + 태그 10개 제안
5. drafts/blog_{주제}.md 저장

## 거절 규칙
- 출처 불명 통계·인용은 본문에 넣지 않음
- 사용자 확인 없이 실제 발행(게시) 금지

수강생 실습 — 미니 Agent 만들기 (50분)

  • 본인 Skill 1~2개 고르기 (3주차 과제물 활용)
  • Agent의 책임 한 줄로 적기 — 예: "주제만 받으면 자료조사 + 초안까지 만들어 주는 작가"
  • .claude/agents/my-agent.md 생성 — 위 샘플의 frontmatter 복사
  • 시스템 프롬프트 작성 — 역할 / 입력 종류 / 호출할 Skill / 출력 규칙 / 거절 규칙
  • 테스트 호출 — 메인 대화에서 Agent에게 작업 위임
  • 개선 루프 — 결과가 어색하면 시스템 프롬프트 수정

좋은 Agent 시스템 프롬프트 체크리스트

  • 한 가지 책임에 집중 (Agent를 만능으로 만들지 말 것)
  • 어떤 Skill을 언제 부르는지 명시
  • 모호한 입력에 대한 기본 동작 정의 (다시 묻기 / 기본값)
  • "사용자 확인 없이 하면 안 되는 일" 명시 (메일 발송, 외부 API 호출 등)
  • 출력 양식 (요약 → 본문 / 표 / 단계별 리포트 등) 고정

운영 팁 · 마무리

  • 권한: Agent에 Bash·Write 같은 강력한 도구를 줄 때는 /permissions로 위험 명령 가드
  • 컨텍스트 절약: Agent는 자체 컨텍스트를 가지므로, 큰 자료 검색을 위임해 메인 대화를 깨끗하게 유지
  • 버전 관리: .claude/agents/와 .claude/skills/ 둘 다 Git으로 관리 — 잘 굴러가던 프롬프트를 망쳤을 때 되돌릴 수 있어야 함
  • 디버깅: Agent가 헛다리 짚으면 → 시스템 프롬프트의 "역할" 또는 "입력 분류 규칙"을 더 구체적으로
