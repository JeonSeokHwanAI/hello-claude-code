WEEK 03

2주차 시연 1개를 직접 만들기 🚀

2주차에 본 5가지 시연 중 본인이 선택한 1개를 직접 만듭니다. 강사가 처음부터 함께 만들어 주는 구조 — 블로그 분석·유튜브 정리·Calendar/Sheets 연동·풀스택 설문 페이지 중 본인 선택.

날짜2025-06-03 (수)
시간21:00~ (기본 2h)
난이도초급
선수 학습Week 2
제공 자료Automation_pipeline_design

학습 목표

  • Skill의 내부 구조(폴더, frontmatter, 본문) 이해
  • 첫 번째 Skill 1개 라이브로 작성·호출 성공
  • 본인 시나리오로 Skill 1~2개 완성 시작
  • 4주차 Agent 변환 재료 확보

시나리오 카탈로그

메인 5종은 2주차 시연을 그대로 만들어 보는 코스, 확장 응용은 본인 상황에 맞춘 변형 코스입니다.

🎯 메인 — 2주차 시연 그대로 만들기

📝

블로그 분석 도구

본인이 좋아하는 블로거의 글 수집 + 분석 Skill 미니 버전 직접 작성

🎬

유튜브 채널 분석

관심 채널 등록 + 자막 요약 + 핵심 인사이트 추출

📅

Calendar 자동화

정기 알림 / 일정 일괄 등록 / 주간 일정 자동 요약 (MCP)

📊

Sheets 자동화

분석 결과 자동 정리 / 데이터 동기화 / 협업 워크플로우 (MCP)

🌐

설문 페이지 + DB + 배포 ⭐

HTML 폼 + Supabase or Sheets 저장 + Vercel 배포 — 풀스택 1사이클

✨ 확장 응용 — 본인 상황 맞춤

✍️

네이버 블로그 자동 작성

2주차 /persona 결과 활용 → 본인 톤으로 글 초안 생성

🎞️

쇼츠/릴스 스크립트

30초 후킹 + 본문 + CTA. 유튜브 분석 결과를 재료로

📋

회의록 → 액션 아이템

결정사항·TODO·담당자·마감 자동 분리 후 표로

✉️

메일 회신 초안

받은 메일 + 의도 → 비즈니스 톤 초안 2종

📈

일일/주간 업무 보고서

작업 파일·메모 → 양식 맞춤 보고서 자동 생성

📑

엑셀 데이터 정리

지저분한 엑셀 → 정렬·중복 제거·요약 표 (Sheets 응용)

커리큘럼 구성

1ST · 25min · 사고 과정

이런 Skill은 어떻게 만들까? (설계 사고)

  • 케이스 스터디: 2주차에 쓴 /search·/review·/report 도구를 강사가 어떻게 설계했는가
  • 4단계 설계 사고: 관찰 → 쪼개기 → 입출력 정의 → 매뉴얼 작성
  • command vs Skill 차이 — 같은 도구를 Skill로 만들면 어떻게 달라지나
  • 좋은 Skill 5원칙
2ND · 25min · 첫 Skill

나만의 첫 Skill 라이브 작성

  • .claude/skills/ 폴더 구조 / frontmatter / 본문 마크다운
  • 강사 라이브: "주간 업무 일지" Skill 작성 → 즉시 호출 → 디버깅
  • 시나리오 카탈로그 투표 → 2~3개 깊게 다루기
  • 본인 말투 학습 시연 (블로그·페르소나 케이스, 2주차 /persona 와 연결)
3RD · 25min · 본인 작업

본인 시나리오 적용 + 시연

  • 2주차 과제로 정해 온 "내가 만들고 싶은 Skill" 작성 시작
  • 강사 1:1 코칭 (15분)
  • 자원자 시연 발표 2~3명 (1인 2분)
  • 우수 사례 → 4주차 Agent 데모 재료

이번 주 과제

🛠️ 본인 Skill 1주일 운영

  • Skill 1~2개 완성해서 1주일 동안 실제로 사용
  • 사용 로그·개선 포인트 메모 (4주차 Agent 재료)
  • 본인 Skill 묶기 좋은 짝 찾기 (예: 회의록 + 메일 회신)
