네이버 검색 API 발급받기 🟢

"API가 뭔지도 모른다"는 가정에서 출발합니다. 네이버 개발자센터에 가입해 검색 API를 신청하고 Client ID·Client Secret을 발급받아, 크롬 확장에서 쓸 수 있게 만드는 데까지 한 단계씩 따라갑니다.

소요 시간약 10분
비용무료
준비물네이버 계정
00 용어 먼저 01 발급 단계 02 키 사용·테스트 03 주의·한도

먼저, 용어부터 (1분)

API — 다른 회사의 서비스(네이버 검색)를 내 프로그램에서 불러 쓰는 "콘센트"입니다. 정해진 주소로 요청하면 데이터(JSON)를 돌려줍니다.
Client ID / Client Secret — "이 요청은 나(내 앱)다"를 증명하는 아이디 / 비밀번호 한 쌍. 네이버가 발급해 줍니다. Secret은 비밀번호이므로 외부에 노출 금지.
검색 API — 네이버의 블로그·뉴스·쇼핑·이미지 등 검색 결과를 데이터로 받아오는 API. 이번 크롬 확장이 쓰는 게 이것입니다.
핵심: 우리가 할 일은 딱 하나 — 네이버에서 Client ID와 Secret 두 글자열을 받아오는 것. 그러면 코드(또는 Claude가 만든 확장)가 그걸 들고 네이버에 검색을 요청합니다.

발급 단계 (따라만 하세요)

1

네이버 개발자센터 접속 · 로그인

developers.naver.com 에 들어가 평소 쓰는 네이버 계정으로 로그인합니다. (별도 개발자 가입 절차 없이 네이버 로그인이면 됩니다.)

2

"오픈 API 이용 신청" 열기

상단 메뉴 Products → 서비스 API → 검색으로 들어가거나, 곧장 애플리케이션 등록 페이지로 이동합니다. 검색 API 설명 페이지 아래의 "오픈 API 이용 신청" 버튼을 눌러도 같은 화면이 나옵니다.

3

애플리케이션 정보 입력

  • 애플리케이션 이름: 아무거나. 예) naver-search-extension (나중에 화면에 표시될 이름)
  • 사용 API: 드롭다운에서 "검색" 선택
  • 비로그인 오픈 API 서비스 환경: "WEB 설정" 추가 → 웹 서비스 URL에 http://localhost 입력 (크롬 확장 실습용으로 충분)
웹 서비스 URL은 "이 주소에서 호출할 거다"라는 표시일 뿐, 실습 단계에서는 http://localhost 로 두면 됩니다.
4

등록 → Client ID·Secret 확인

등록하기를 누르면 바로 애플리케이션이 만들어지고, 화면에 Client ID와 Client Secret이 나옵니다. (Secret은 가려져 있으면 옆의 "보기" 버튼으로 펼칩니다.) 이 두 값을 복사해 안전한 곳에 메모해 두세요.

# 발급 결과 예시 (값은 사람마다 다릅니다)
Client ID     : aB12cD34eF56gH78iJ90
Client Secret : Kl1mNo2pQr

발급한 키, 어떻게 쓰나

네이버 검색 API는 요청 헤더에 위 두 값을 실어 보냅니다. 아래는 "claude" 라는 단어를 블로그에서 검색하는 예시입니다. (터미널에 그대로 붙여 동작 확인 가능 — 본인 키로 바꾸세요.)

curl "https://openapi.naver.com/v1/search/blog.json?query=claude" \
  -H "X-Naver-Client-Id: 발급받은_CLIENT_ID" \
  -H "X-Naver-Client-Secret: 발급받은_CLIENT_SECRET"
크롬 확장에서는 이 Client ID·Secret을 확장의 설정(options) 화면에 입력해 저장하고, 코드가 검색할 때마다 헤더에 넣어 호출합니다. 오늘 받은 NaverAPI-extension.zip이 정확히 이 구조입니다.
Claude에게 맡기는 법: "네이버 검색 API Client ID/Secret 발급받았어. 이 키로 블로그 검색해서 결과 보여주는 크롬 확장 만들어줘" 라고 하면, 키 입력 화면·호출 코드·결과 렌더링까지 만들어 줍니다.

꼭 알아둘 주의 · 한도

  • Client Secret은 비밀번호 — GitHub·블로그·스크린샷에 그대로 올리지 마세요. 노출되면 애플리케이션 화면에서 재발급.
  • 무료 호출 한도 — 검색 API는 애플리케이션당 하루 25,000회까지 무료. 실습·개인 도구로는 충분합니다.
  • 검색 종류별 주소가 다름 — /search/blog.json, /search/news.json, /search/shop.json 등. 쓰려는 종류를 신청 시 "검색"으로 한 번에 묶어 쓸 수 있습니다.
  • 키가 안 먹힐 때 — 401/403 오류면 ① ID/Secret 오타 ② "사용 API"에 검색이 빠짐 ③ 헤더 이름 오타(X-Naver-Client-Id) 순으로 점검.
