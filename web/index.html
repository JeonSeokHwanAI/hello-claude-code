Week 1

강의 소개 + Claude Code 익숙해지기

첫 주는 강의 전체 흐름과 도구 친해지기에 집중합니다. 사례발표는 없습니다 — 처음부터 같이 시작하는 시간이에요.

Week 2~4

사례발표 → 본 강의

매 회차 첫 시간은 수강생 사례발표로 시작합니다. 지난 주 배운 내용을 본인 일에 어떻게 써봤는지 5분 이내로 짧게 공유합니다. 그 후에 그 주의 본 강의가 이어집니다.

왜 사례발표를 하나요?

이 강의는 직접 해본 사람만 다음 주차를 따라올 수 있도록 설계되었습니다. 간단한 예제라도 본인 손으로 한 번 돌려봐야 그 다음 단계가 의미 있게 다가옵니다. 사례발표는 부담 주려는 게 아니라, 여러분이 강의 전에 한 번이라도 손을 움직이게 하는 장치예요.

  • 분량: 1인 5분 이내, 화면 공유 또는 결과물만 공유 OK
  • 완성도: 따라가다 막힌 지점 공유도 환영 — 그게 더 좋은 사례입니다
  • 대상: 자원자 우선, 매주 2~3명. 4주 동안 1번 이상 발표 권장
  • 준비: 다음 주 발표하고 싶다고 카톡방에 미리 손들기

FAQ

자주 묻는 질문

코딩을 전혀 몰라도 따라갈 수 있나요?

네. 1~2주차는 클릭과 대화만으로 충분합니다. 3주차부터는 본인 업무에 맞춘 응용이지만, 코드 작성은 Claude가 합니다. 여러분은 "지시·검수"만 하면 돼요.

비용이 따로 드나요? Anthropic 결제가 필요한가요?

네, Anthropic 유료 결제가 필요합니다. 본 강의는 Claude Code의 실습 분량이 많아 무료 플랜으로는 사용량 한도에 막힙니다. 강의 시작 전 Pro 플랜(월 $20) 이상을 결제해 주세요.

결제 방법

  1. claude.ai 로그인
  2. 좌측 하단 프로필 → Settings → Plans & Billing
  3. Pro 또는 그 이상 플랜 선택 → 카드 결제
  4. VS Code의 Claude Code 확장에서 동일 계정으로 로그인 시 자동 인식
설치가 어렵거나 처음 해봐요. 따라갈 수 있을까요?

걱정 마세요. 5월 1주차에 설치 과정 동영상을 미리 배포해 드립니다. 영상을 보면서 천천히 따라 하시면 누구나 완료할 수 있도록 구성되어 있습니다. 그래도 막히는 부분이 있으면 사전 설문이나 강사 연락처로 문의해 주세요 — 강의 첫날(5/20) 전에 1:1로 도와드리고, 5/13 Kickoff 시간에도 환경 점검을 함께 봐드립니다.

※ 본 강의는 개인 PC 사용을 전제로 합니다. VS Code + Claude Code 확장 환경에서만 진행되며, 웹 버전(claude.ai)으로는 실습이 불가능합니다.

Mac과 Windows 모두 지원되나요?

네. 둘 다 동일하게 진행됩니다. Windows 사용자는 Git for Windows를 추가로 설치해야 합니다.

강의 녹화본이 제공되나요?

네, 녹화본이 제공됩니다. 매 회차 강의는 녹화되어 수강생에게 공유됩니다. 실시간 참여가 어려운 분도 복습하거나 따라잡을 수 있습니다.

강의 종료 시간이 정해져 있지 않은 이유가 있나요?

매 회차 기본 2시간 분량으로 준비하지만, 질문이 많거나 실습이 길어지면 더 진행됩니다. 충분히 익히고 가시는 게 우선이에요.
