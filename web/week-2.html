WEEK 02

Skill로 어디까지 가능한가 (시연 회차)

이번 주는 Skill이 어떻게 다양하게 활용되는지 보여주는 시간입니다. 콘텐츠 분석부터 외부 서비스 연동, 풀스택 웹 빌드까지 — 같은 Skill 패턴이 5가지 전혀 다른 분야로 확장되는 모습을 봅니다. 다음 주엔 그중 하나를 직접 만들어 봅니다.

날짜2025-05-27 (수)
시간21:00~ (기본 2h)
난이도입문~초급
선수 학습Week 1
제공 자료Automation_hub

학습 목표

  • "왜 ChatGPT 웹이 아니라 Claude Code인가" 한 문장으로 설명
  • Skill / Command / MCP = AI에게 일을 시키는 3가지 방식 구분
  • 5가지 시연을 보고 다음 주에 직접 만들 1개를 선택
  • "AI가 자료 분석부터 웹사이트 배포까지 한다"는 감각 체득

커리큘럼 구성

참고 자료: Automation_hub Ch 01~04 (이론) + 강사 자체 제작 도구 AI Blog Writer

1ST · 25min · 이론

왜 Claude Code이고, Skill이란 무엇인가

  • AI의 종류와 코딩 AI의 위치
  • 웹 챗봇 vs CLI/IDE AI — 파일·실행·연속 작업
  • Claude Code 핵심 구조: 입력 → 작업 → 출력
  • Skill = AI 업무 매뉴얼 — 한 패턴이 어디까지 확장될 수 있는가
  • 오늘 시연 5종의 공통점 미리보기 — "다 같은 Skill 패턴"
2ND · 25min · 라이브 데모 ①

강사 자체 도구 + 외부 서비스 연동

  • 📝 블로그 분석 — AI Blog Writer
       /search → /review → /report → /persona
  • 🎬 유튜브 채널 분석 — 강사 도구
       채널 등록·즐겨찾기·영상 요약
  • 📅 Google Calendar (MCP)
       "내일 2시 회의 잡아줘" / "이번 주 일정 정리"
  • 📊 Google Sheets (MCP)
       분석 결과를 시트에 자동 정리
3RD · 25min · 라이브 데모 ②

풀스택 한 방에 — 설문조사 페이지 + DB + 배포

  • 🌐 설문조사 웹사이트 라이브 빌드
       Claude에게 "설문 페이지 만들어 — 응답은 DB에 저장, Vercel 배포까지" 한 줄 요청
  • HTML 폼 자동 생성 (질문 5~7개)
  • 데이터 저장 옵션 비교 시연
       옵션 A: Google Sheets (간단·무료)
       옵션 B: Supabase (실서비스용·무료 한도)
  • 🚀 Vercel 배포 라이브 — `vercel` 명령 한 번으로 실제 도메인 발급
  • 강의 시작 25분 만에 실제 동작하는 웹사이트 + DB 완성
  • 마무리: "오늘 본 5가지 중 1개를 다음 주 본인이 직접 만든다" — 선택 안내

5가지 시연 한눈에 보기

다음 주에는 이 중 1개를 골라 직접 만듭니다. 오늘은 일단 다 보세요.

① 📝 블로그 분석

AI Blog Writer (강사 자체 제작)

  • 강사가 실제로 매일 쓰는 도구 — 가짜 예제 아님
  • 네이버 블로거는 한국 일반 사용자에 즉시 공감
  • 결과: 분석 HTML 리포트 1개
② 🎬 유튜브 분석

채널·영상 자동 정리

  • 채널 등록·즐겨찾기·주제별 필터링
  • 영상 자막 → 핵심 요약
  • 본인 콘텐츠 인풋 관리에 즉시 활용
③ 📅 Google Calendar (MCP)

일정을 자연어로 다루기

  • "내일 2시 OO 미팅" → 자동 등록
  • "이번 주 일정 정리" → 깔끔한 요약
  • 정기 분석을 알림으로 자동화
④ 📊 Google Sheets (MCP)

외부 시스템과 협업

  • 분석 결과를 시트에 자동 정리
  • 지저분한 데이터를 정렬·요약
  • 다른 사람과 손쉬운 공유
⑤ 🌐 설문조사 페이지 + DB + 배포 ⭐

풀스택 한 방에 — 25분 만에 실서비스

  • 프론트엔드: Claude가 HTML 폼 자동 생성
  • 백엔드 옵션 비교:
    · Google Sheets — 가장 간단, 무료, 설문 결과 보기 직관적
    · Supabase — 실서비스용 PostgreSQL, 무료 한도, 확장성 ↑
  • 배포: Vercel — vercel 한 줄 → 진짜 도메인
  • 이 강의 사이트도 같은 방식으로 만들어졌습니다
  • "AI가 코드를 쓰면 일반인도 풀스택 빌드 가능"의 살아있는 증거
이번 주는 시연만 — 직접 안 따라 해도 됩니다. 5개 중에 "이거 만들어 보고 싶다" 1개만 정해 오세요. 다음 주 그걸 함께 만듭니다.
