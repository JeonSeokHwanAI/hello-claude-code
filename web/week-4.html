WEEK 04

코워크 + Agent 연동 🤖

Agent에 들어가기 전에 코워크(Claude와 함께 일하는 법)를 먼저 다집니다. 이어서 설문 페이지 + Supabase + Vercel을 빠르게 빌드하고, 그것을 Agent로 운영하는 데까지 갑니다. 2~3주차에 만든 본인 Skill도 Agent로 묶습니다.

날짜2026-06-10 (수)
시간21:00~ (기본 2h)
난이도초급~중급
선수 학습Week 3
제공 자료Supabase 셋업 가이드

학습 목표

  • 코워크 — Claude와 효율적으로 협업하는 패턴 체화
  • Skill과 Agent의 차이를 한 문장으로 설명
  • .claude/agents/ 폴더에 본인 Agent 1개 작성·호출
  • Skill 1~2개를 묶은 미니 워크플로우 동작 확인
  • 강의 이후 학습 경로 인지 (MCP, SDK, 커뮤니티)

Skill vs Agent

  • Skill — 정해진 절차(매뉴얼). 부르면 그대로 실행. 비유: 엑셀 매크로
  • Agent — 목표를 받고 어떤 Skill·도구를 쓸지 스스로 결정. 비유: 비서에게 일 맡기기
  • Agent 사용 시 장점: 컨텍스트 절약, 자동 분기, 병렬 작업

🌐 설문 페이지 풀스택 — 만들고, Agent로 운영하기

먼저 풀스택 한 사이클을 빠르게 빌드한 뒤, 그 운영을 Agent에게 맡깁니다. (빌드 비중은 작게 — 핵심은 "Agent로 운영")

STEP 1 · 빠른 빌드

HTML 폼 + Supabase + Vercel

  • Claude에게 "설문 페이지 만들어 — 응답은 DB 저장, Vercel 배포까지" 한 줄
  • HTML 폼 자동 생성 → Supabase에 응답 저장 (무료 한도)
  • vercel 한 번으로 실제 도메인 발급 — 이 강의 사이트도 같은 방식
STEP 2 · Agent로 운영 ⭐

설문-운영-에이전트

  • 응답 모니터링 → 통계 자동 정리 → 시트 갱신
  • 답변자에게 메일 회신까지 한 번에
  • "만든 것"을 "굴러가게" 만드는 게 Agent의 역할

커리큘럼 구성

1ST · 25min · 코워크

Claude와 함께 일하는 법 (Co-work)

  • 코워크 마인드셋 — Claude는 "도구"가 아니라 "동료"
  • 역할 분담 패턴: 내가 결정 / Claude가 실행 / 함께 검토
  • 컨텍스트 공유: CLAUDE.md, 슬래시 커맨드, 파일 첨부
  • 리뷰 루프: 결과 → 피드백 → 재실행 사이클을 짧게
  • Git으로 함께 일하기 — 커밋 메시지, PR, 코드 리뷰 협업
  • 막혔을 때 빠져나오기: /clear, 새 세션, 더 작은 단위로 쪼개기
2ND · 25min · Agent

Agent 개념 + Skill 연동 ⭐

  • Skill vs Agent 한 장 정리
  • Subagent 종류: Explore / Plan / general-purpose
  • 라이브 비교: (a) Skill만 호출 vs (b) Agent + Skill
  • 강사 라이브: 설문-운영-에이전트 — 방금 빌드한 설문을 Agent로 운영
  • 좋은 Agent 체크리스트 5개
  • 본인이 2~3주차에 만든 Skill을 묶는 Agent 작성
3RD · 25min

운영 팁 + 시연 발표 + 수료

  • 권한 관리 (/permissions) — 위험 명령 가드
  • 자원자 시연 발표 (Agent 자랑 타임)
  • 더 깊이: 공식 문서, MCP, Claude Agent SDK
  • 4주 회고 + 수료

Agent 샘플 3종 — 본인 결과물별 묶음

2~3주차에 무엇을 만들었느냐에 따라 어울리는 Agent 패턴이 달라집니다.
