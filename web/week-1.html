WEEK 01

Claude Code 첫 만남

"내 컴퓨터에서 Claude가 코드를 만진다"는 감각을 첫날에 체득합니다. 환경은 이미 준비된 상태에서 바로 첫 응용 프로그램까지.

날짜2026-05-20 (수)
시간21:00~ (기본 2h)
난이도입문
선수 학습Week 0 환경 구축
제공 자료hello Claude-Code

학습 목표

90분 후 여러분은:

  • Claude Code가 ChatGPT 웹과 어떻게 다른지 한 문장으로 설명한다
  • VS Code의 Claude 사이드바에서 첫 메시지를 보낼 수 있다
  • 권한 팝업(Allow/Deny)이 뜨는 이유를 안다
  • Claude와 대화하며 자기소개 HTML 페이지 1개를 완성한다

커리큘럼 구성

3교시 × 30분 + 쉬는 시간

1ST · 25min

Claude Code란 무엇인가

  • ChatGPT 웹 vs Claude Code — 파일 접근·실행 능력의 차이
  • 잘하는 일 / 못하는 일 한눈에
  • 4주 로드맵 안내
  • 라이브 데모: 빈 폴더에서 회의록 정리시키기
  • 권한 모드 한 컷 정리
2ND · 25min

첫 대화 실습

  • 실습 폴더 열기 (Ctrl+K, Ctrl+O)
  • "이 폴더에 뭐 있어?" — 첫 메시지
  • 파일 읽히기 — 권한 팝업 처음 만나기
  • hello.py 작성 → 실행까지
  • 자주 쓰는 표현 4종
3RD · 25min

자기소개 페이지 만들기

  • about-me-template.html 시작점에서 출발
  • 강사 라이브 시연 8분
  • 본인 작업 12분 (강사 1:1 코칭)
  • 자원자 시연 발표

강의 자료 다운로드

📦 1주차 실습 자료

  • 실습 폴더(자기소개 페이지 템플릿 등)가 들어 있는 압축 파일입니다.
  • 내려받아 압축을 풀고, 그 폴더를 VS Code로 열어 강의를 따라오세요.
