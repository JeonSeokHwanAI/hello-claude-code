YouTube Data API 발급받기 🔴

"구글 클라우드가 뭔지도 모른다"는 가정에서 출발합니다. Google Cloud Console에서 프로젝트를 만들고 YouTube Data API v3를 켠 뒤 API 키 한 줄을 발급받아, 영상·채널 데이터를 불러올 수 있게 만드는 데까지 한 단계씩 따라갑니다.

소요 시간약 10분
비용무료
준비물구글 계정
00 용어 먼저 01 발급 단계 02 키 사용·테스트 03 할당량·주의

먼저, 용어부터 (1분)

Google Cloud Console — 구글의 각종 API를 켜고 끄고 키를 관리하는 관제실 같은 웹사이트입니다. 무료로 가입하며, 단순 API 키 발급에는 결제 등록도 필요 없습니다.
프로젝트(Project) — API·키·설정을 담는 "폴더". 먼저 프로젝트를 하나 만들고, 그 안에서 API를 켭니다.
YouTube Data API v3 — 유튜브의 영상·채널·검색·댓글 데이터를 받아오는 API. 우리가 켤 대상입니다.
API 키 — "이 요청은 내 프로젝트다"를 증명하는 한 줄짜리 문자열. 네이버처럼 ID/Secret 쌍이 아니라 키 하나면 됩니다(공개 데이터 읽기용).
핵심: 할 일은 세 가지 — ① 프로젝트 만들기 ② YouTube Data API v3 켜기 ③ API 키 하나 발급. 끝나면 그 키로 유튜브 데이터를 불러옵니다.

발급 단계 (따라만 하세요)

1

Google Cloud Console 접속 · 로그인

console.cloud.google.com 에 들어가 구글 계정으로 로그인합니다. 처음이면 약관 동의 창이 한 번 뜹니다 — 동의하고 진행.

2

새 프로젝트 만들기

  • 상단 바 왼쪽의 프로젝트 선택 드롭다운 클릭 → "새 프로젝트"
  • 프로젝트 이름 입력. 예) youtube-explorer → 만들기
  • 생성 후, 같은 드롭다운에서 방금 만든 프로젝트가 선택됐는지 확인
3

YouTube Data API v3 켜기(사용 설정)

  • 왼쪽 메뉴 ≡ → API 및 서비스 → 라이브러리
  • 검색창에 "YouTube Data API v3" 입력 → 결과 클릭
  • 사용(Enable) 버튼 클릭 → 잠시 후 "사용 설정됨"으로 바뀜
4

API 키 발급

  • API 및 서비스 → 사용자 인증 정보(Credentials) 이동
  • 상단 + 사용자 인증 정보 만들기 → API 키 선택
  • 키가 즉시 생성되어 화면에 표시됩니다 — 복사해 안전한 곳에 메모
# 발급 결과 예시 (값은 사람마다 다릅니다)
API key : AIzaSyD-xxxxxxxxxxxxxxxxxxxxxxxxxxxx
5

(권장) 키 제한 걸기

방금 만든 키 이름을 클릭 → API 제한사항에서 "키 제한" → YouTube Data API v3만 체크 → 저장. 이렇게 하면 키가 새어 나가도 유튜브 외 다른 API로는 못 쓰게 막힙니다.

발급한 키, 어떻게 쓰나

YouTube Data API는 주소 끝에 key=발급키를 붙여 호출합니다. 아래는 "claude code"로 영상을 검색하는 예시입니다. (터미널에 붙여 동작 확인 — 본인 키로 바꾸세요.)

curl "https://www.googleapis.com/youtube/v3/search?part=snippet&q=claude+code&type=video&maxResults=5&key=발급받은_API_KEY"
네이버와 다른 점: 네이버는 헤더에 ID·Secret 두 개, 유튜브는 주소에 키 하나. 공개 데이터(검색·영상정보·채널정보) 읽기는 API 키만으로 충분하고, 내 계정의 비공개 데이터를 다룰 때만 OAuth가 추가로 필요합니다.
Claude에게 맡기는 법: "YouTube Data API 키 발급받았어. 이 키로 채널 검색·영상 목록 불러오는 도구 만들어줘" 라고 하면 호출 코드·결과 정리까지 만들어 줍니다.

할당량(Quota)·주의

  • 무료 할당량 — 프로젝트당 하루 10,000 units. 호출마다 "단가"가 다른 게 핵심입니다.
  • 검색은 비쌈 — search.list 1회 = 100 units. 즉 하루 검색은 약 100회면 소진. 반면 videos.list·channels.list 같은 단순 조회는 1회 = 1 unit이라 수천 번 가능.
  • 실수 호출도 차감 — 잘못된 요청도 최소 1 unit 부과됩니다. 검색을 남발하지 말고 ID를 받아 videos.list로 상세를 받는 식으로 아끼세요.
  • 키는 비밀 — GitHub·스크린샷에 노출 금지. 새면 콘솔에서 키 삭제 후 재발급.
  • 할당량이 모자라면 — 콘솔의 "할당량 증가 요청 양식"으로 추가 신청 가능(승인 필요).
출처(2026년 6월 기준 확인): YouTube Data API — Getting Started (공식). 공식 문서 표기: "10,000 units per day combined for all other endpoints", search.list는 100 units/회.
