## 1교시 — 이론 (25분)

**Slide 4 — AI의 종류** (Ch 01, 3분)
- 대화형 / 이미지 / 코딩 / 특화
- "코딩 AI ≠ 코딩만 하는 AI" — 파일·실행을 다루는 AI

**Slide 5 — 웹 챗봇 vs CLI/IDE AI** (Ch 02, 4분)
| | ChatGPT 웹 | Claude Code |
|---|----------|-------------|
| 파일 접근 | ❌ | ✅ |
| 실행 능력 | ❌ | ✅ |
| 연속 작업 | 단편적 | 컨텍스트 유지 |

**Slide 6 — Claude Code의 작동 흐름** (Ch 03, 5분)
```
입력 → 작업 → 출력
(요청)  (Read/Write/Run)  (파일/응답)
```
- **마크다운**이 공용어인 이유: AI가 가장 잘 읽고 쓰는 텍스트 포맷

**Slide 7 — 잠깐, "마크다운"이 뭐죠?** (3분)
- `#` 제목, `-` 목록, `**굵게**` 만으로 구조화된 글
- AI에게 일을 시킬 때, 결과물을 받을 때 모두 사용
- 메모장으로도 작성 가능

**Slide 8 — Skill = AI 업무 매뉴얼** (Ch 04, 5분)
- 사람의 SOP(표준작업절차)에 비유
- 한번 잘 써두면 반복 호출
- `/명령어` 형태로 부름

**Slide 9 — 사례 미리보기** (3분)
- 품의서: 55분 → 7분
- 매뉴얼 번역: 2~3일 → 5~15분
- "이게 왜 가능한가" — Skill에 절차가 잘 적혀 있어서

**Slide 10 — 핵심 한 줄 요약** (2분)
"Claude는 마크다운으로 일을 받고, 마크다운으로 결과를 낸다. Skill은 그 마크다운으로 쓰인 매뉴얼이다."

## 🎓 강사 메모

### 자주 나올 질문
- **Q. 견적서가 영수증·세금계산서면 다른 Skill 필요한가?** A. 같은 `/img-to-docs` 로 추출 후 양식만 바꿔도 됨. 4주차 Agent에서 자동 분기 가능.
- **Q. 한국어 OCR 정확한가?** A. 인쇄된 견적서는 매우 잘됨. 손글씨/저화질은 약함.
- **Q. 회사 견적서 올려도 되나?** A. 강의에서는 더미만 사용. 실제 도입 시 보안 정책 확인 필요.
