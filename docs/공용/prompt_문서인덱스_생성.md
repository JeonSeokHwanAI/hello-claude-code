# 문서 인덱스 페이지 생성 프롬프트

> 외부 경로의 폴더/파일 구조를 스캔하여 번호 기반 인덱스 페이지를 한 번에 생성하는 프롬프트.
> 사용 시 `{대상 경로}`와 `{저장 경로}`만 교체한다.

---

## 프롬프트

```
아래 경로의 폴더/파일 구조를 스캔하여 문서 인덱스 페이지를 만들어줘.

[대상 경로]
{대상 경로}

[저장 경로]
{저장 경로}

[작업 순서]
1. 대상 경로의 전체 폴더/파일 구조를 먼저 확인한다
2. 폴더별로 번호를 매긴다 (루트=0, 첫 번째 하위 폴더=1, ...)
3. 각 폴더 안의 파일에 소수점 번호를 매긴다 (1.1, 1.2, ...)
4. 모든 파일을 읽고 한 줄 용도 설명을 작성한다
5. 파일 간 관계를 분석하여 활용 가이드를 작성한다
6. 마크다운 테이블로 정리하여 저장한다

[출력 형식]
- 제목: `# {폴더명} 문서 리스트`
- 원본 경로 표시
- 활용 가이드 테이블: 파일들의 조합으로 달성할 수 있는 목적별 사용 경로를 정리
- 섹션별 테이블: `| 번호 | 파일명 | 용도 | 비고 |`
- 파일명에 상대 경로 링크를 건다 (저장 경로 기준, VS Code 마크다운 미리보기에서 클릭 가능하도록)
- 파일명에 공백이 있으면 `%20`으로 인코딩한다
- 용도는 한 줄로 간결하게 쓴다 (파일을 실제로 읽고 핵심 역할을 요약)
- 비고에는 활용 가이드의 목적별로 해당 파일이 어떤 역할인지 표시한다

[참고 예시]
```

## 참고

- 생성 후 "X.X번 파일 읽어줘"로 번호 기반 파일 조회 가능
- 상대 경로 링크는 VS Code 마크다운 미리보기(`Ctrl+Shift+V`)에서 클릭 가능
- 절대 경로 링크는 VS Code 보안 제한으로 동작하지 않음
- 활용 가이드는 파일 내용을 분석한 뒤 목적별 사용 경로를 자동으로 도출한다
