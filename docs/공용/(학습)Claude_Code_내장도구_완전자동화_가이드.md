# Claude Code 내장 도구 - 완전자동화 가이드

Claude Code에는 프로젝트 스킬, 에이전트, 명령어와 별개로 **처음부터 내장된 도구**가 있습니다. 이 도구들만으로도 상당 수준의 업무 자동화가 가능합니다.

이 문서는 **코드를 작성하지 않는 사무업무자** 관점에서, 내장 도구가 무엇이고 어떻게 조합하면 완전자동화에 가까워지는지를 정리합니다.

---

## 먼저 이해하면 좋은 핵심 개념

### "내장 도구"란?

- Claude Code를 설치하면 **별도 설정 없이 바로 사용할 수 있는 기능**입니다.
- 프로젝트 스킬(`.claude/skills/`)이나 커스텀 명령어(`.claude/commands/`)는 사용자가 추가한 것이고, 내장 도구는 Claude Code 자체에 포함된 것입니다.

### "완전자동화"란?

- 사람이 **"이렇게 해줘"라고 한 번만 말하면**, AI가 알아서 검색 → 분석 → 판단 → 실행 → 저장까지 수행하는 것을 의미합니다.
- 내장 도구는 이 흐름의 각 단계를 담당하는 **기본 부품**입니다.

---

## 요약

### 핵심 (자동화를 가능하게 하는 것)

| 구분                              | 핵심                                       |
| --------------------------------- | ------------------------------------------ |
| **Agent / Bash**                  | 작업 실행의 엔진 — AI 판단 + 스크립트 실행 |
| **WebSearch / WebFetch / Chrome** | 외부 정보 수집·웹 조작                     |
| **MCP**                           | 외부 서비스(Notion, Slack 등) 연결         |
| **권한 모드 (auto-accept)**       | 중단 없는 연속 실행                        |
| **Hooks**                         | 이벤트 발생 시 자동 추가 작업              |
| **/loop**                         | 주기적 반복 실행                           |

### 보조 (핵심을 돕는 것)

| 구분                                  | 핵심                                     |
| ------------------------------------- | ---------------------------------------- |
| **Read / Write / Edit / Glob / Grep** | 파일 읽기·쓰기·검색 — 핵심 도구의 입출력 |
| **병렬 실행 / 백그라운드**            | 효율 향상 — 동시 처리, 대기 없는 진행    |
| **/batch / /compact / /resume**       | 일괄 변경, 컨텍스트 관리, 세션 재개      |

**핵심 메시지**: 자연어로 원하는 결과만 말하면, Claude Code가 이 도구들을 알아서 조합하여 실행합니다. 도구 이름을 외울 필요 없이, "해줘"라고 말하면 됩니다.

---

## 1부: 자동화 핵심 도구 vs 보조 도구

내장 도구 13개를 **자동화에 필수적인 핵심 도구**와 **핵심 도구를 보조하는 도구**로 나눕니다.

### 핵심 도구 — 자동화의 엔진 (6개)

이것들이 없으면 자동화 자체가 불가능합니다.

| 도구          | 비유               | 자동화에서의 역할                                                                       |
| ------------- | ------------------ | --------------------------------------------------------------------------------------- |
| **Agent**     | AI 담당자 파견     | 복잡한 작업을 별도 AI에게 위임. 병렬 실행으로 동시 처리. **자동화의 핵심 엔진**         |
| **Bash**      | 명령 실행기        | 스크립트/스킬 실행, 시스템 제어, 백그라운드 실행. **모든 실행의 기반**                  |
| **WebSearch** | 구글 검색          | 외부 정보 실시간 수집. **정보 수집 자동화의 시작점**                                    |
| **WebFetch**  | 웹페이지 읽기      | 특정 URL의 내용 수집·분석. **웹 데이터 자동 수집** (토큰절약 위해 파이썬 스크래핑 권장) |
| **Chrome**    | 브라우저 자동 조작 | 로그인, 폼 입력, 클릭, 스크린샷. **사람 조작이 필요한 웹 작업 대체**                    |
| **MCP**       | 외부 서비스 연결   | Notion, Slack 등 외부 서비스와 직접 통신. **외부 시스템 연동 자동화**                   |

#### Agent vs Bash 핵심 차이

- **Bash**: "이 명령어 실행해" → 시킨 것만 정확히 수행
- **Agent**: "이 주제 조사해서 정리해줘" → 스스로 검색하고, 판단하고, 결과를 만들어냄

단, Bash로 AI 판단이 포함된 스크립트(스킬)를 실행하면 Bash도 AI 판단 영역으로 확장됩니다. 즉, **도구 자체의 차이보다 "무엇을 실행하느냐"가 더 중요**합니다.

---

### 보조 도구 — 핵심 도구를 돕는 부품 (7개)

핵심 도구가 작업을 수행할 때 **읽고, 쓰고, 찾는** 역할을 합니다. 자동화 흐름에서 자연어 요청 시 AI가 알아서 선택하므로 사용자가 직접 지정할 필요 없습니다.

| 도구           | 역할                 | 핵심 도구와의 관계                     |
| -------------- | -------------------- | -------------------------------------- |
| **Read**       | 파일/PDF/이미지 읽기 | Agent가 분석할 자료를 읽어옴           |
| **Write**      | 파일 생성/저장       | Agent/Bash 실행 결과를 파일로 저장     |
| **Edit**       | 파일 부분 수정       | 기존 문서의 특정 부분만 변경           |
| **MultiEdit**  | 여러 파일 동시 수정  | /batch 등 일괄 작업의 실행 수단        |
| **Glob**       | 패턴으로 파일 찾기   | 처리 대상 파일 목록 확보               |
| **Grep**       | 내용으로 파일 검색   | 특정 키워드가 포함된 파일 탐색         |
| **TaskOutput** | 백그라운드 결과 수신 | Bash/Agent 백그라운드 작업의 결과 확인 |

> **NotebookEdit** (Jupyter 노트북 편집)은 데이터 분석 전용이므로 일반 사무 자동화와는 무관합니다.

## 2부: 완전자동화를 위한 내장 기능

핵심 도구를 **언제, 어떻게, 얼마나 자율적으로** 실행할지를 결정하는 기능들입니다.

### 핵심 자동화 기능 — 이것이 없으면 "자동"이 아님

#### 권한 모드 (자동 승인)

| 모드               | 설명                        | 전환 방법                                    |
| ------------------ | --------------------------- | -------------------------------------------- |
| **기본 모드**      | 매번 사용자에게 허락을 받음 | 기본값                                       |
| **자동 수락 모드** | 도구 실행을 자동으로 허용   | `Shift+Tab` 또는 CLI에서 `--permission-mode` |
| **계획 모드**      | 계획만 세우고 실행 전 확인  | `/plan`                                      |

> 완전자동화를 위해서는 **자동 수락 모드**가 필요하지만, 안전을 위해 신중하게 사용해야 합니다.<br>
> 안전이 중요하면 자동화가 부족해지고, 자동화를 강조하면 안전성이 부족해지니 각자 하는 작업 및 환경에 맞게 적절한 모드 및 권한관리를 해야 합니다.

#### Hooks (이벤트 기반 자동화)

특정 이벤트가 발생하면 **자동으로 추가 작업**을 실행하는 기능입니다. 사람이 지시하지 않아도 조건이 맞으면 알아서 실행됩니다.

| 이벤트               | 발동 시점              | 활용 예시                 |
| -------------------- | ---------------------- | ------------------------- |
| **SessionStart**     | 세션이 시작될 때       | 환경 점검, 서버 상태 확인 |
| **UserPromptSubmit** | 사용자가 입력하기 직전 | 입력 내용 검증, 보완      |
| **PreToolUse**       | 도구 실행 직전         | 위험한 작업 차단          |
| **PostToolUse**      | 도구 실행 완료 후      | 테스트 실행, 알림 발송    |
| **TaskCompleted**    | 작업 완료 시           | 다음 단계 자동 진행       |

#### /loop (반복 실행)

| 기능      | 설명                           | 예시                                      |
| --------- | ------------------------------ | ----------------------------------------- |
| **/loop** | 지정 간격으로 명령을 반복 실행 | `/loop 10m /daily-review` → 10분마다 반복 |

> 단, 대화 세션이 열려있는 동안만 작동합니다.

### 보조 자동화 기능 — 효율을 높여주는 기능

| 기능                | 설명                                          | 예시                                    |
| ------------------- | --------------------------------------------- | --------------------------------------- |
| **Agent 병렬**      | 서브에이전트 여러 개 동시 실행                | "경쟁사 A, B, C 동시에 조사해줘"        |
| **Bash 병렬**       | 명령어 여러 개 동시 실행                      | "PDF 5개 한번에 변환해줘"               |
| **에이전트 팀**     | 역할별 에이전트가 협업                        | "조사팀 + 분석팀 + 보고서팀 동시 가동"  |
| **백그라운드 실행** | 오래 걸리는 작업을 뒤로 보내고 다른 작업 진행 | Ctrl+B로 전환, TaskOutput으로 결과 확인 |
| **/batch**          | 여러 파일에 같은 패턴의 변경 일괄 적용        | "모든 문서에 날짜 태그 추가해줘"        |
| **/compact**        | 대화 내용 압축하여 컨텍스트 확보              | 긴 작업 중 컨텍스트 부족 시             |
| **/resume**         | 이전 세션 이어서 작업                         | 끊긴 작업 재개                          |

## 3부: 자동화 조합 패턴 (실전 시나리오)

### 패턴 1: 정보 수집 → 분석 → 보고서

```
[요청] "AI 업계 최신 트렌드 3가지를 조사해서 보고서로 만들어줘"

[자동 실행 흐름]
WebSearch → 키워드로 검색
WebFetch → 주요 기사 3~5개 내용 수집
Read → 기존에 저장된 관련 자료 확인
(AI 판단) → 트렌드 분류, 중요도 평가
Write → 보고서 파일 저장
```

### 패턴 2: 대량 파일 일괄 처리

```
[요청] "이 폴더의 마크다운 파일 전부에 날짜 태그 추가해줘"

[자동 실행 흐름]
Glob → 폴더 안의 *.md 파일 목록 확인
Read → 각 파일 내용 확인
(AI 판단) → 이미 태그가 있는지 판단
MultiEdit → 없는 파일에만 일괄 추가
```

### 패턴 3: 웹 자동화

```
[요청] "이 웹사이트에서 가격표를 가져와서 표로 정리해줘"

[자동 실행 흐름]
Chrome → 웹사이트 접속, 가격표 페이지 이동
(AI 판단) → 테이블 구조 파악
Write → 마크다운 표로 정리하여 저장
```

### 패턴 4: 병렬 조사 + 종합

```
[요청] "경쟁사 3곳을 동시에 분석해서 비교표 만들어줘"

[자동 실행 흐름]
Agent 1 → A사 웹사이트 조사 (WebFetch + WebSearch)
Agent 2 → B사 웹사이트 조사 (WebFetch + WebSearch)
Agent 3 → C사 웹사이트 조사 (WebFetch + WebSearch)
(3개 동시 실행, 결과 수집)
(AI 판단) → 비교 항목 정리
Write → 비교표 문서 저장
```

### 패턴 5: 모니터링 + 자동 대응

```
[요청] "/loop 30m 이 사이트 상태 확인하고 변경 있으면 알려줘"

[30분마다 자동 실행]
WebFetch → 대상 URL 내용 수집
Read → 이전에 저장된 내용과 비교
(AI 판단) → 변경 여부 판단
변경 감지 시 → Bash로 알림 스크립트 실행
```

### 패턴 6: 문서 검색 → 업데이트 → 동기화

```
[요청] "모든 프로젝트 문서에서 '2025'를 '2026'으로 바꿔줘"

[자동 실행 흐름]
Grep → '2025' 포함 파일 전체 검색
Read → 각 파일에서 맥락 확인 (날짜인지, 버전인지 등)
(AI 판단) → 바꿔야 할 것과 유지해야 할 것 구분
MultiEdit → 판단된 파일만 일괄 수정
```

### 내장 도구와 스킬의 관계

```
내장 도구 = 범용 엔진 (어떤 차에도 들어가는 기본 엔진)
스킬     = 전문 부품 (특정 작업에 최적화된 장비)
```

- 내장 도구만으로 **70~80%의 일반 업무 자동화** 가능
- 스킬을 추가하면 **전문 영역까지 확장** 가능
- 별도 (바이브)코딩 및 외부 서비스를 이용 시 **완벽에 가까운 고도화된 자동화** 가능

## 4부: 단축키 및 내장 슬래시 명령어

### 자동화에 유용한 단축키

| 단축키        | 기능                                    |
| ------------- | --------------------------------------- |
| **Ctrl+B**    | 실행 중인 작업을 백그라운드로 전환      |
| **Ctrl+C**    | 현재 작업 취소                          |
| **Ctrl+F**    | 모든 백그라운드 에이전트 중지           |
| **Ctrl+O**    | 상세 실행 과정 보기/숨기기              |
| **Ctrl+T**    | 작업 목록 보기                          |
| **Shift+Tab** | 권한 모드 전환 (기본 ↔ 자동수락 ↔ 계획) |
| **Esc + Esc** | 이전 시점으로 되돌리기                  |

### 자동화 관련 내장 슬래시 명령어

| 명령어     | 기능                                     |
| ---------- | ---------------------------------------- |
| `/batch`   | 여러 파일에 같은 패턴의 변경을 일괄 적용 |
| `/loop`    | 지정 간격으로 명령을 반복 실행           |
| `/plan`    | 실행 전 계획 모드로 전환                 |
| `/context` | 현재 컨텍스트 사용량 확인                |
| `/compact` | 대화 내용을 압축하여 컨텍스트 확보       |
| `/resume`  | 이전 세션 이어서 작업                    |
| `/diff`    | 변경사항 확인                            |
| `/tasks`   | 백그라운드 작업 목록 확인                |
