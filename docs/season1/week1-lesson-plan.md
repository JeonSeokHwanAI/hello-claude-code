## 1교시 — Claude Code란? (25분)

### Slide 4 — Claude를 어디서 써봤나요? (1분)
- 채팅 투표: claude.ai / ChatGPT / 안 써봄
- "오늘은 그것과 다른 Claude를 봅니다"

### Slide 5 — 한 그림으로 보는 차이 (3분)
```
[ChatGPT 웹]
당신 ─── 대화 ───> AI
        (텍스트만)

[Claude Code]
당신 ─── 대화 ───> AI ─── 직접 ───> 내 컴퓨터의 파일
                          (읽고/쓰고/실행)
```

**핵심 한 문장**: Claude Code는 **내 PC를 직접 만지는** AI다.

### Slide 6 — 그래서 뭐가 좋은가 (3분)
- ✅ "이 폴더 정리해줘" — 진짜로 정리됨
- ✅ "이 견적서 PDF 5장 요약해줘" — 진짜로 읽음
- ✅ "이 코드 고쳐줘" — 진짜로 수정됨
- ❌ ChatGPT 웹: 항상 "여기 코드를 복사해서 써보세요" 까지가 끝

### Slide 7 — 잘하는 일 / 못하는 일 (3분)
| 잘하는 일 | 못하는 일 |
|---------|----------|
| 반복 문서 작성 | 인터넷 실시간 정보 (별도 도구 필요) |
| 파일 정리/요약 | 매우 큰 코드 베이스를 한 번에 |
| 코드 작성·디버깅 | 사실 검증 없는 단정 |
| 데이터 변환 | 복잡한 도메인 의사결정 |

### Slide 8 — 4주 로드맵 (2분)
- W1: 첫 만남 (오늘) — 응용 프로그램 1개 만들기
- W2: Skill 사용 — 품의서 자동화
- W3: Skill 직접 만들기 — 블로그·SNS·업무
- W4: Agent로 확장 — 만든 Skill을 비서에게 맡기기

### Slide 9 — 라이브 데모 (10분) ⭐
**시나리오**: 빈 폴더에서 "오늘 회의록 정리해줘"

1. 강사가 빈 폴더 열기
2. 회의록 텍스트 파일 한 개 미리 둠
3. Claude에게 "이 폴더에 있는 회의록을 정리해서 결정사항·할 일로 나눠줘"
4. **권한 팝업 등장 → 멈춤**
5. "여기서 yes/no 묻는 게 보이죠? 이게 권한 모드입니다"
6. Allow → 결과 보여주기
7. 후속 요청: "결과를 마크다운 파일로 저장해줘" → 파일 생성 시연

### Slide 10 — 권한 모드 한 컷 정리 (3분)
- Claude는 **읽기**, **쓰기**, **실행** 단계마다 멈추고 물어봅니다
- 처음엔 모두 물어봐서 귀찮을 수 있어요 → 익숙해지면 자주 쓰는 건 자동 허용 가능 (3주차)
- 핵심: "내 컴퓨터에서 일하는 AI니까 책임감 있게"

## 2교시 — 첫 대화 실습 (25분)

### Slide 11 — 같이 따라하기 (1분)
- 화면 공유 보면서 똑같이
- 막히면 채팅 — 절대 혼자 끙끙대지 마세요

### Slide 12 — 1단계: 폴더 열기 (3분)
1. Week 0에서 받은 `claude-lecture-workspace` 폴더 열기 (`Ctrl+K, Ctrl+O`)
2. 사이드바 Claude 아이콘 클릭
3. 입력창 보이면 OK

### Slide 13 — 2단계: 첫 메시지 (5분)
입력: `이 폴더에 뭐가 있어?`

**예상 결과**: 폴더 구조를 트리 형태로 보여줌
**짚을 점**: "Claude가 내 폴더를 '본다'는 게 이런 의미예요"

### Slide 14 — 3단계: 파일 읽히기 (5분)
입력: `week1-first-app/samples/about-me-template.html 파일을 보여주고 어떤 내용인지 설명해줘`

**짚을 점**:
- 권한 팝업 → Allow
- Claude가 파일 내용을 읽고 요약함
- "이게 ChatGPT 웹과의 차이입니다"

### Slide 15 — 4단계: 짧은 코드 만들기 (8분)
입력: `이 폴더 안에 hello.py 라는 파일을 만들어서, 'Hello, Claude Code!' 를 출력하는 프로그램을 작성해줘`

**짚을 점**:
- 쓰기 권한 팝업 → Allow
- 파일 생성됨 → VS Code 탐색기에서 확인
- 터미널에서 실행 (강사가 보여주는 정도, 직접은 3주차)

### Slide 16 — 자주 쓰는 표현 (3분)
- "이 파일 ~~ 해줘"
- "방금 만든 거 ~~ 로 바꿔줘"
- "이거 왜 이렇게 했어?" (설명 요청)
- "다시 한 번 처음부터 정리해줘" (리셋)

# 🎓 강사용 보조 메모

## 자주 나올 질문 + 답변

**Q. 비용이 따로 드나요? Anthropic 결제가 필요한가요?**
- A. **네, Anthropic 유료 결제 필수**입니다. 본 강의는 실습 분량이 많아 무료 플랜으로는 사용량 한도에 막힙니다. 강의 전 Pro 이상 결제를 안내드렸습니다.

**Q. 코드를 못 짜는데 따라갈 수 있나요?**
- A. 1~2주차는 "지시·검수"만 합니다. 코드 작성은 Claude가 합니다. 3주차부터 본인 업무에 맞춘 응용으로 갑니다.

**Q. 회사 보안상 클라우드로 파일이 가도 되나요?**
- A. Claude API에 입력으로 보내지는 건 맞습니다. 회사 정책 확인 필요. 강의에서는 더미 데이터만 사용합니다.

**Q. 응답이 영어로 나와요**
- A. CLAUDE.md에 "응답은 한국어로" 한 줄을 넣어두면 일관됩니다 (이미 실습 폴더에 포함).

## 시간 압박 대응 (계획 B)

- 1교시 데모가 길어지면 → 2교시 4단계(`hello.py`) 생략
- 3교시가 빠듯하면 → 시연 시간을 5분으로 단축, 자유 작업 15분 확보
- 환경 이슈가 5명 이상이면 → 1교시 시작 시 10분 트러블슈팅 타임으로 변경
