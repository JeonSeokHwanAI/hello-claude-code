# 신청 완료 메일 자동 발송 — 설치 가이드

> 신청이 들어오면 **자동으로 메일 2통**이 나갑니다.
> ① 신청자에게 — 접수 확인 + 결제 안내 (금액 자동 분기)
> ② 사장님 네이버 메일로 — 신청 알림 + 챙길 것 요약
>
> 소요 시간 **약 15분**. 코드는 [`apps-script-mailer.gs`](./apps-script-mailer.gs)

---

## 동작 방식

```
신청 폼 제출
   ↓
Supabase에 저장          ← 지금까지 되던 부분
   ↓
Database Webhook 발동     ← 이번에 붙이는 부분
   ↓
Apps Script (구글)
   ↓
Gmail로 메일 2통 발송
```

**보내는 주소**는 Apps Script를 만든 **구글 계정(Gmail)** 이 됩니다.
**받는 주소**는 네이버든 뭐든 상관없습니다 — 사장님 알림은 네이버 메일로 갑니다.

> 발신을 네이버 주소로 바꾸고 싶으시면 맨 아래 [부록](#부록--보내는-주소를-네이버로-바꾸고-싶다면)을 보세요. 안 하셔도 됩니다.

---

## 1단계 — Apps Script 프로젝트 만들기

1. [script.google.com](https://script.google.com) 접속 (강의에 쓸 구글 계정으로 로그인)
2. 왼쪽 위 **새 프로젝트**
3. 프로젝트 이름을 `월간클로드 2기 메일러` 로 변경 (왼쪽 위 "제목 없는 프로젝트" 클릭)
4. 기본으로 들어있는 `function myFunction() {}` 코드를 **전부 지우고**,
   [`apps-script-mailer.gs`](./apps-script-mailer.gs) 내용을 **통째로 붙여넣기**
5. 💾 저장 (Ctrl+S)

---

## 2단계 — CONFIG 채우기

붙여넣은 코드 맨 위 `CONFIG` 부분만 고치면 됩니다.

```js
const CONFIG = {
  OWNER_EMAIL: 'YOUR_NAVER_EMAIL@naver.com',   // ← 사장님 네이버 메일
  FROM_ALIAS: '',                              // ← 그대로 비워두세요 (Gmail로 발송)
  FROM_NAME: '월간클로드',
  SECRET: 'CHANGE_ME_아무거나_길게_20자이상',    // ← 아무 문자열이나 길게
  BANK: '○○은행 000-0000-0000-00 (예금주: 전석환)',  // ← 입금 계좌
  ...
};
```

**꼭 바꿔야 하는 3개**

| 항목 | 넣을 값 |
|---|---|
| `OWNER_EMAIL` | 신청 알림 받으실 **네이버 메일 주소** |
| `SECRET` | 아무 문자열이나 길게. 예: `mc2gi-2026-a7f3k9x2m5` <br>남이 이 주소로 장난 못 치게 막는 열쇠입니다 |
| `BANK` | **입금 계좌** — 신청자 메일에 그대로 들어갑니다 |

`LANDING_URL` 은 배포 후 모집 페이지 주소를 넣으면 메일 하단에 링크가 붙습니다. 비워두셔도 됩니다.

저장(Ctrl+S).

---

## 3단계 — 메일이 실제로 나가는지 먼저 확인

웹훅을 붙이기 전에 메일부터 테스트합니다.

1. 편집기 위쪽 함수 선택 드롭다운에서 **`testSendMail`** 선택
2. **▶ 실행** 클릭
3. 처음이라면 권한 승인 창이 뜹니다:
   - **권한 검토** → 계정 선택
   - "Google에서 확인하지 않은 앱입니다" 경고 → **고급** → **월간클로드 2기 메일러(안전하지 않음)으로 이동**
   - **허용**

   > 본인이 만든 스크립트라 경고가 뜨는 게 정상입니다. 외부 앱이 아닙니다.

4. 사장님 네이버 메일함에 **메일 2통**이 오면 성공입니다.
   - `[월간클로드 2기] 신청이 접수되었습니다 — 결제 안내` (신청자용 미리보기)
   - `[2기 신청] 홍길동(테스트) · 500,000원 할인` (알림용)

메일 내용을 보시고 문구나 계좌를 고치고 싶으면 지금 고치세요.

## 4단계 — 웹 앱으로 배포

1. 오른쪽 위 **배포 → 새 배포**
2. 왼쪽 ⚙️ **유형 선택 → 웹 앱**
3. 설정을 **정확히** 이렇게:

   | 항목 | 값 |
   |---|---|
   | 설명 | `v1` (아무거나) |
   | 다음 사용자로 실행 | **나** |
   | 액세스 권한이 있는 사용자 | **모든 사용자** ⚠️ |

   > "모든 사용자"로 해야 Supabase가 호출할 수 있습니다. 대신 `SECRET` 토큰으로 막아뒀으니, 토큰을 모르면 아무것도 못 합니다.

4. **배포** → 나오는 **웹 앱 URL** 복사

   ```
   https://script.google.com/macros/s/AKfycb....../exec
   ```

---

## 5단계 — Supabase 웹훅 연결

1. [Supabase 대시보드](https://supabase.com/dashboard) → 프로젝트 선택
2. 왼쪽 메뉴 **Integrations → Database Webhooks**
   *(또는 Database → Webhooks)*
3. **Create a new hook**
4. 이렇게 채웁니다:

   | 항목 | 값 |
   |---|---|
   | Name | `season2-apply-mail` |
   | Table | `season2_applications` |
   | Events | **Insert** 만 체크 |
   | Type | **HTTP Request** |
   | Method | **POST** |
   | URL | 4단계에서 복사한 주소 **뒤에 `?token=...` 을 붙여서** |

   **URL은 이런 모양이 됩니다** — `SECRET`에 넣으신 값을 그대로 이어붙이세요:

   ```
   https://script.google.com/macros/s/AKfycb....../exec?token=mc2gi-2026-a7f3k9x2m5
   ```

   | HTTP Headers | `Content-Type: application/json` |

5. **Create webhook**

## 6단계 — 전체 흐름 테스트

실제 신청 폼으로 한 번 넣어봅니다.

1. 신청 페이지(`apply.html`)를 열고 **본인 메일 주소로** 신청서를 제출
2. 확인할 것:
   - [ ] 신청자 메일함에 **접수 확인 + 결제 안내** 도착
   - [ ] 네이버 메일에 **신청 알림** 도착
   - [ ] 금액이 맞는지 (블크업 13기 체크 → 50만원 / 아니오 → 65만원)
3. Supabase **Table Editor**에서 테스트 행 삭제

메일이 안 오면 아래 문제 해결을 보세요.

---

## 문제 해결

**메일이 아예 안 옴**
- Supabase → Database Webhooks → 해당 훅 클릭 → **Logs** 확인
- `401 unauthorized` → URL 뒤 `?token=` 값과 코드의 `SECRET`이 다릅니다
- `403` 또는 HTML 응답 → 배포 설정에서 "액세스 권한"이 **모든 사용자**가 아닙니다

**코드를 고쳤는데 반영이 안 됨**
- Apps Script는 **다시 배포해야** 반영됩니다.
- **배포 → 배포 관리 → ✏️ 편집 → 버전: 새 버전 → 배포**
- 이렇게 하면 URL은 그대로 유지됩니다. (새 배포를 또 만들면 URL이 바뀌니 주의)

**하루에 몇 통까지?**
- 일반 Gmail 계정 기준 **하루 100통**. 신청 1건당 2통이니 하루 50명까지 가능합니다.
- 정원 8명이라 걱정하실 일은 없습니다.

**스팸함으로 들어감**
- 신청자에게 "메일이 안 보이면 스팸함도 확인해 주세요"라고 이미 페이지에 안내되어 있습니다.
- 신경 쓰이시면 부록의 네이버 별칭 설정을 하시면 도달률이 조금 나아집니다.

**자동 메일이 실패해도**
- 신청 데이터는 Supabase에 **이미 저장된 뒤**라 사라지지 않습니다.
- 실패하면 사장님께 `⚠️ 자동 메일 발송 실패` 알림이 따로 갑니다. 대시보드 보고 직접 회신하시면 됩니다.

## 부록 — 보내는 주소를 네이버로 바꾸고 싶다면

기본은 Gmail 발송입니다. 굳이 안 하셔도 되지만, `@naver.com`으로 나가게 하려면:

1. **네이버 메일** → 환경설정 → POP3/IMAP 설정 → **SMTP 사용 On**
2. **Gmail** → 설정(⚙️) → **계정 및 가져오기** → "다른 주소에서 메일 보내기" → **다른 이메일 주소 추가**
   - 네이버 주소 입력
   - SMTP 서버 `smtp.naver.com`, 포트 `465`, SSL
   - 아이디/비밀번호는 네이버 계정 (2단계 인증 쓰시면 애플리케이션 비밀번호)
3. 네이버로 온 확인 메일의 링크를 눌러 인증
4. Apps Script 코드에서:
   ```js
   FROM_ALIAS: 'YOUR_NAVER_EMAIL@naver.com',
   ```
5. **다시 배포** (4단계 참고)

별칭이 제대로 등록 안 됐으면 코드가 알아서 Gmail로 보내니, 메일이 안 나가는 사고는 없습니다.
