  • Skill과 Agent의 차이를 한 문장으로 설명

Skill vs Agent

  • Skill — 정해진 절차(매뉴얼). 부르면 그대로 실행. 비유: 엑셀 매크로
  • Agent — 목표를 받고 어떤 Skill·도구를 쓸지 스스로 결정. 비유: 비서에게 일 맡기기
  • Agent 사용 시 장점: 컨텍스트 절약, 자동 분기, 병렬 작업

커리큘럼 구성 — 3가지 주제

1ST · Agent

Agent 개념 익히기 — NaverBlogWriter

  • Skill vs Agent 한 장 정리 — "절차" vs "스스로 판단"
  • Subagent 종류: Explore / Plan / general-purpose
  • NaverBlogWriter로 Agent 활용법 라이브 확인 — 주제만 던지면 수집·작성까지
  • 라이브 비교: (a) Skill만 호출 vs (b) Agent + Skill
  • 좋은 Agent 체크리스트 5개
2ND · API ⭐

API 활용하기 — NaverAPI 크롬 익스텐션

  • 외부 NaverAPI를 코드에서 호출하는 흐름 이해
  • 크롬 확장 구조: manifest · background · content/search · options
  • API 키 관리와 호출, 결과를 화면에 렌더링
  • chrome://extensions 개발자 모드로 로드·디버깅
  • 오늘 자료(extension + 소스 원본)로 PRD ↔ 결과물 비교
3RD · Claude 앱

Claude 앱 사용하기 — Chat · Claude Code

  • Chat(claude.ai) — 대화·기획·문서 작업에 강함
  • Claude Code — 코드·파일·터미널 실작업에 강함
  • 언제 무엇을 쓸지: 상황별 선택 기준
  • 두 앱을 오가며 일하는 실전 흐름
  • 4주 회고 + 수료, 이후 학습 경로(MCP · SDK)
