00
개강 전 세팅

개강 전에 온라인으로 한 시간 모여서 같이 설치합니다. 혼자 하다 막히는 것보다 이게 훨씬 빨라요.

  • VS Code · Claude Code · Node.js 설치
  • 구글 개발자 계정 등록 ($25)

🖥 온라인 1시간 · 날짜는 카톡 모임방에서 공지해요
01
내 웹사이트 만들기

한 장짜리가 아니라 제대로 된 사이트를 만듭니다. 소개 · 메뉴/작업물 · 오시는길 · 문의까지.

  • 여러 섹션을 갖춘 소개 사이트 완성
  • ⭐ 색·배치·글·사진 내 마음대로 바꾸기
  • ⭐ "이 사이트처럼 해줘"가 먹히는 이유
  • 폰에서 봐도 안 깨지게 · CLAUDE.md에 내 취향 적어두기
✅ 여기까지: 내 사이트가 열리고, 내가 고칠 수 있다
02
안드로이드 앱 만들기

웹페이지 말고 진짜 앱이에요. 수업 중에 폰으로 QR 찍으면 바로 실행됩니다.

  • 무거운 개발 도구 없이 시작 (빌드는 클라우드가)
  • 🎉 내 폰에서 내 앱 켜보기
  • 유형별 화면 만들기 — 가게앱 · 작업물앱 · 도구앱
  • 아이콘 · 앱 이름 · 첫 화면
✅ 여기까지: 내 폰에서 앱이 돌아간다
03
배포하기 ⭐

제일 중요한 날. 웹사이트는 Vercel에, 앱은 구글 플레이에 따로따로 올립니다.

  • 🌐 GitHub 올리고 → Vercel로 배포 → 내 주소 생김
  • 🌐 카톡 공유 미리보기 · 검색 노출 · 개인정보처리방침
  • 📱 앱 파일 만들어서 → Play Console에 등록
  • 📱 스토어 등록정보 채우기 (여기가 은근 까다로워요)
  • 🎉 플레이스토어에서 내 앱 받아 설치
✅ 여기까지: 웹 주소 + 스토어에서 받는 내 앱
04
공공데이터 활용하기

날씨, 미세먼지, 동네 축제 같은 진짜 데이터를 내 앱이나 사이트에 끌어옵니다.

  • API가 뭔지 — "남의 서버에 물어보고 답 받아오기"
  • 공공데이터포털에서 원하는 데이터 찾고 키 받기
  • 내 화면에 붙이고 다시 배포
  • 비밀키 흘리지 않게 다루는 법
✅ 여기까지: 실시간 데이터가 화면에 뜬다

🎯 만들고 싶은 게 다 다르니까, 유형별로 갈라집니다

정식 공개에만 조건이 하나 붙어요

구글이 개인 개발자 계정에 조건을 걸어놨습니다. 정식으로 공개하기 전에 테스터 12명이 14일 동안 계속 참여한 테스트를 거쳐야 해요. 이 12명을 혼자 모으기가 은근히 어려워서, 여기까지 와놓고 접는 분이 많습니다.

사업자등록증이 있다면

이 조건이 아예 없어요

개인 계정이라면

같이 넘으면 됩니다

수강생끼리 서로 테스터가 되어주면 12명은 금방 채워집니다. 혼자면 막혔을 자리인데, 같이 하니까 넘어가요.

FAQ

자주 묻는 질문

코딩을 하나도 몰라요. 앱까지 만들 수 있나요?

네. 애초에 코딩을 못 한다는 전제로 만든 강의입니다. 코드는 Claude가 씁니다. 하시는 일은 "이렇게 만들어줘"라고 말하고, 결과를 보고, "이건 좀 바꿔줘"라고 다시 말하는 거예요.

앱도 똑같습니다. 무거운 개발 도구는 안 깔아도 되고, 앱 파일 만드는 건 클라우드가 대신 해줘요.

정말 4주 안에 구글 플레이에 올라가나요?

올리는 것까지는 3주차에 됩니다. 앱을 등록하고 올려서, 플레이스토어에서 받아 내 폰에 까는 것까지가 3주차 목표예요. 링크 보내면 지인도 스토어에서 받을 수 있습니다.

다만 아무나 검색해서 받는 정식 공개에는 조건이 하나 붙어요. 구글이 개인 계정에 "테스터 12명 × 14일"을 요구하거든요. 사업자등록증이 있으면 이 조건이 없고, 개인이시면 수강생끼리 서로 테스터가 되어 채웁니다.

"월간클로드"가 뭔가요? 매달 돈을 내야 하나요?

아니요, 추가 비용 없습니다. 이렇게 굴러갑니다.

  • 정규 4주 과정 — 유료. 한 번만 들으면 됩니다 (지금 모집 중인 것)
  • 월간클로드 — 수료하신 분들 대상으로 매달 무료로 여는 자리

월간 자리에서는 그달에 새로 나온 주제·기술·트렌드를 다룹니다. AI는 반년이면 분위기가 바뀌어서 한 번 배우고 끝내면 금방 뒤처지거든요. 수강료는 한 번만 내시고 계속 이어가시라는 뜻이에요.

비용이 또 드나요?

네, 수강료 말고 두 가지가 더 듭니다. 미리 정확히 말씀드릴게요.

  • Claude Pro 구독 — 월 $20 이상 (실습이 많아 무료로는 중간에 막힙니다)
  • 구글 개발자 등록 — $25 (한 번만. 앱을 스토어에 올리려면 꼭 필요해요)

Vercel·GitHub·공공데이터포털이랑 앱 빌드는 전부 무료 범위에서 합니다.

아이폰 앱도 만드나요?

이번엔 안드로이드만 합니다. iOS는 애플 개발자 등록이 연 $99인 데다 심사도 훨씬 까다로워서 4주 안에 넣기가 어려워요.

대신 웹사이트는 아이폰에서도 똑같이 열립니다. 안드로이드 폰이 없으시면 신청서에 알려주세요. 실습 대안을 드릴게요.

구글 개발자 계정을 왜 미리 만들어야 하나요?

신원 확인 때문입니다. 보통 하루면 끝나는데 서류가 어긋나면 2주까지 갑니다. 3주차 당일에 계정이 없으면 그날 실습을 못 하시게 돼요.

신청하시면 등록 방법을 스크린샷과 함께 보내드립니다. 어렵지 않아요.

Week 0은 뭘 하나요?

개강 전에 온라인으로 한 시간 모입니다. VS Code랑 Claude Code 설치하고, 개발자 계정 등록도 같이 봐드려요.

혼자 설치하다 막히면 하루를 날리는데, 같이 하면 한 시간이면 끝납니다. 날짜는 수강생이 모이면 카톡 모임방에서 공지해요. 개강 전에 다들 되시는 시간으로 잡습니다.

3주차·4주차가 연휴인데 강의를 하나요?

네, 밤 시간 화상강의라 예정대로 합니다. 연휴에 못 오시는 분은 녹화본을 보시고 주말 특강에 오시면 돼요. 특히 3주차는 꼭 챙겨서 엽니다.

4주 안에 못 따라가면 어떡하죠?

괜찮습니다. 수료하시면 매달 열리는 월간클로드에 계속 오실 수 있어요. 못 끝낸 건 거기서 이어가시면 됩니다.

한 달, 두 달 지나면서 되어가는 것 — 그게 이 프로그램이 지향하는 방식이에요.

신청하면 어떻게 진행되나요?

신청서는 1분이면 끝납니다. 이름·연락처와 실습 환경만 여쭤봐요. 받으면 1~2일 안에 결제 안내를 메일로 보내드리고, 결제가 확인되면 월간클로드 2기 카톡방에 초대해 드립니다.

카톡방에서 Week 0 세팅 세션 날짜를 공지하고, 강의 자료랑 공지도 전부 여기로 올라갑니다. 막히는 게 있으면 언제든 물어보시면 돼요.
