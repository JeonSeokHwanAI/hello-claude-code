CHAPTER 01

AI의 종류 — 우리가 쓸 건 어느 것?

AI를 크게 나누면

💬
대화형 AI (챗봇)

질문에 답변하고, 글을 쓰고, 요약한다

ChatGPT · Claude · Gemini
🎨
이미지 생성 AI

텍스트를 입력하면 이미지를 만들어준다

Midjourney · DALL-E · Stable Diffusion
⌨️
코딩 AI ⭐

코드를 작성하고, 파일을 만들고, 업무를 자동화한다

Claude Code · GitHub Copilot · OpenAI Codex
🎯
특화 AI

번역·음성·영상 등 특정 분야에 최적화

DeepL · Whisper · Sora

일반 챗봇은 "답변"만 한다
코딩 AI는 "실행"까지 한다

파일을 읽고, 코드를 실행하고, 결과물(PDF·Excel·HTML)을 직접 생성합니다.
프로그래밍을 몰라도 한국어로 지시하면 됩니다.

CHAPTER 02

왜 CLI(터미널·IDE)로 사용하는가?

웹 챗봇 vs CLI AI

🌐 웹 챗봇 (ChatGPT, claude.ai) ⌨️ CLI AI (Claude Code)
파일 접근파일을 직접 업로드해야 한다내 컴퓨터의 파일을 직접 읽고 쓴다
실행 능력코드를 보여줄 뿐이다코드를 직접 실행하고 결과를 만든다
연속 작업매번 복사-붙여넣기 반복여러 단계를 자동으로 이어서 처리
결과물텍스트 답변실제 파일 (PDF, Excel, HTML) 생성

웹 챗봇은 조언자
CLI AI는 실행자다

같은 요청, 다른 결과

🌐 웹 챗봇에게 "PDF 번역해줘"
  • PDF를 업로드한다
  • 번역된 텍스트를 돌려준다
  • 레이아웃? 없다. 텍스트 덩어리
  • 워드에 다시 옮긴다
  • 서식을 다시 잡는다
VS
⌨️ CLI AI에게 "PDF 번역해줘"
  • 파일 경로만 알려준다
  • 원본 레이아웃을 분석한다
  • 텍스트를 번역한다
  • 레이아웃 유지한 PDF 생성
  • → 번역된 PDF 파일이 바로 나온다

업무 처리 흐름의 차이

웹 챗봇 방식
파일 업로드
→
AI 텍스트 답변
→
사람 복붙
→
사람 서식
→
사람 저장
CLI AI 방식
사람 명령어
→
AI: 읽기 → 처리 → 저장
→
결과 파일 완성

CHAPTER 04

Skill — AI에게 업무 매뉴얼 주기

스킬이란?

AI에게 미리 정의해둔
업무 매뉴얼

/스킬이름 형태로 호출하면 AI가 정해진 절차대로 작업을 수행합니다.

/img-to-docs

이미지 → 마크다운 → Excel

/approval-doc

견적서·목록 → 품의서 HTML

/translate-pdf

PDF → 번역 PDF (레이아웃 유지)

데모 ① 품의서 — 사람 vs AI

단계 🧑 사람 (~55분) 🤖 AI (~7분)
1견적서 확인 (5분)견적서 폴더에 넣기 (1분)
2Excel에 품목·금액 타이핑 (15분)/img-to-docs 견적서.png xlsx (2분)
3오타·금액 검산 (5분)Excel 열어 확인 (1분)
4품의서 양식 열기 (2분)/approval-doc 부품목록.xlsx (2분)
5제목·본문·비용표 작성 (15분)HTML 복사 → 그룹웨어 붙이기 (1분)
6HTML 표 정렬·서식 (10분)
7최종 확인 후 상신 (3분)

55분  →  7분

오타 위험 ↓ · 양식 자동화 · 명령어 한 줄로 반복

데모 ② 매뉴얼 번역 — 사람 vs AI

항목 🧑 사람 🤖 AI
소요 시간2~3일5~15분
레이아웃수동 복원 필요자동 유지
기술 용어일일이 검수업계 표준 자동 적용
반복 번역매번 같은 노력/translate-pdf 한 줄

Claude Code 확장 설치

  1. VS Code 실행
  2. 좌측 사이드바 Extensions 클릭 (또는 Ctrl+Shift+X)
  3. 검색창에 Claude Code 입력
  4. Anthropic 제공 확장 → Install
  5. 사이드바 Claude 아이콘 클릭
  6. Anthropic 계정으로 로그인 (Pro 결제 필요)

자세한 설치 과정은 사전 준비 섹션과 5월 1주차에 배포될 설치 동영상을 참고하세요.
