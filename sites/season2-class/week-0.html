WEEK 00 · 개강 전

같이 설치하기

혼자 설치하다 막히면 하루가 날아가지만, 같이 하면 한 시간이면 끝납니다. 다만 딱 하나, 구글 플레이 개발자 계정만은 이 세션 전에 신청해 두셔야 합니다.

날짜조율 중 · 카톡방 공지
시간온라인 1시간
준비물노트북 · 안드로이드 폰
필수개발자 계정 신청 완료

⚠️ 개발자 계정은 지금 바로 신청하세요

  • 신원 확인에 보통 하루, 길면 2주가 걸립니다. Week 0에서 시작하면 늦습니다.
  • 3주차(9월 28일)에 계정이 없으면 그 회차 실습을 통째로 놓칩니다.
  • Week 0 세션에서는 진행 상황을 함께 점검합니다. 시작하는 자리가 아닙니다.

역산해 보면 이렇습니다

  • 9/28 — 3주차. 스토어 업로드. 계정이 반드시 있어야 합니다
  • 9/14 — 개강. 이때는 이미 신청이 접수돼 있어야 안전합니다
  • Week 0 — 신청 상태 점검. 반려된 분은 여기서 같이 고칩니다
  • 지금 — 신청 ⭐

구글 플레이 개발자 계정 등록

등록비 $25(1회). play.google.com/console/signup ↗ 에서 시작합니다.

먼저 알아두실 것 — 결제로 끝이 아닙니다

  • $25를 내고 계정이 만들어진 뒤에도 세 가지가 더 남습니다.
  • ① 본인 확인(신분증 업로드) → ② 안드로이드 기기 확인 → ③ 전화번호 인증
  • 이 셋이 다 끝나야 앱을 게시할 수 있습니다. ①이 며칠 걸리는 그 병목입니다.
  • ③은 ①이 승인돼야 열립니다. 순서가 걸려 있습니다.
STEP 1

계정 유형 — 개인을 고르세요

  • 한 번 정하면 바꿀 수 없습니다.
  • 사업자등록증이 있어도 이번 기수에는 개인을 권합니다. 기관/단체 계정은 D-U-N-S라는 9자리 사업체 식별번호가 필수인데, 국내 소규모 사업자는 대부분 갖고 있지 않습니다. 무료지만 발급에 며칠~2주가 걸리고, 그 뒤에 구글이 조직 인증을 또 합니다. 두 단계가 순서대로 붙어 개강까지 빠듯합니다.
  • 기관 계정의 이점은 정식 출시에 필요한 테스터 12명 요건 면제 하나인데, 우리는 기수끼리 서로 테스터가 되어주면 됩니다. 그게 이 강의의 구조입니다.
  • 화면 아래쪽 개인 → 시작하기. 위쪽 "조직 유형 선택"은 건드리지 않습니다.
STEP 2

개발자 이름

  • 플레이스토어에서 앱 아래에 표시되는 이름입니다. 최대 50자.
  • 본명과 달라도 됩니다. 가게 이름이나 활동명도 괜찮습니다.
  • 나중에 변경할 수 있지만 심사가 붙습니다.
STEP 3

결제 프로필 — 국가를 반드시 확인

  • 결제 프로필의 국가는 나중에 바꿀 수 없습니다. 단순 청구지 정보가 아니라 세금 처리와 직결됩니다.
  • 한국에 계시면 대한민국 프로필을 고르세요.
  • 예전에 다른 구글 서비스를 등록하며 미국 프로필이 만들어져 있는 경우가 있습니다. 목록에 국가가 표시되니 확인하고 고르세요.
  • "전체 주소 필요" 경고가 뜨면 주소를 마저 채웁니다. 신분증 주소와 똑같이 적으세요 — 어긋나면 본인 확인에서 반려됩니다.
STEP 4

연락처 — 공개되는 것과 아닌 것

  • 개발자 프로필 이메일 — 플레이스토어에 공개됩니다. 개인 메일이 꺼려지면 별도 주소를 쓰세요.
  • Google 연락처 — 공개되지 않습니다. 구글이 연락할 때만 씁니다.
  • 전화번호는 국제 형식으로 넣습니다.
    010-1234-5678  →  +82 10-1234-5678
    ↑ 맨 앞의 0을 뺍니다
  • 인증 문자가 안 오면 십중팔구 +82 010…처럼 0을 남긴 경우입니다.
STEP 5

약관 동의 후 $25 결제

  • 체크 항목 중 위 두 개(개발자 배포 계약 · Console 서비스 약관)가 필수입니다.
  • 일회성 결제이고 갱신은 없습니다. 해외결제 가능한 카드가 필요합니다.
  • ⚠️ 약관에 명시돼 있습니다 — 본인 확인이 불가능하면 등록 수수료는 환불되지 않습니다. 신분증 정보를 정확히 준비하세요.
STEP 6 ⭐

본인 확인 — 여기가 병목입니다

  • 계정이 만들어지면 Play Console 홈에 "개발자 계정 설정 완료" 카드가 뜹니다. 본인 확인 → 시작하기를 눌러 신분증(주민등록증·운전면허증·여권)을 올립니다.
  • 문서를 수정하거나 조작하지 마세요. 인증 실패는 계정에 영향을 줍니다.
  • 이름·주소가 결제 프로필과 일치해야 합니다.
  • 업로드하면 "Google에서 신원 확인 중입니다"로 바뀝니다. 완료되면 메일이 옵니다.
  • 빠르면 당일에 승인됩니다. 강사는 신청한 날 바로 승인됐습니다. 다만 서류가 어긋나면 반려되고 다시 며칠이 가므로 미루지 말고 지금 하세요.
  • 승인되면 이 항목이 목록에서 사라지고, 잠겨 있던 연락처 전화번호 인증이 열립니다.
STEP 7

안드로이드 기기 확인 + 전화번호 인증

  • 기기 확인 — 안드로이드 폰에서 Play 스토어 → "Google Play Console" 앱 설치 → 같은 계정으로 로그인. 1~2분이면 끝납니다. 본인 확인과 무관하게 바로 하실 수 있습니다.
  • 전화번호 인증 — 본인 확인이 승인된 뒤에 열립니다. 먼저 눌러도 "다른 인증 작업을 완료하세요"만 나옵니다.

자주 막히는 지점

인증 문자가 안 옵니다

  • +82 010…처럼 0을 남긴 경우입니다. 앞자리 0을 빼고 +82 10…으로 다시 넣으세요.

D-U-N-S 번호를 요구합니다

  • 기관/단체를 선택하셨습니다. 뒤로 가서 개인으로 바꾸세요.
  • 참고로 D&B 공식 조회 페이지는 미국 사업체 전용이라 한국 사업자는 검색해도 나오지 않습니다. 국내는 NICE디앤비를 거쳐야 하고 며칠~2주 걸립니다.

본인 확인이 반려됐습니다

  • 신분증과 결제 프로필의 이름·주소가 다른 경우가 대부분입니다. 서류와 똑같이 맞춰 다시 제출하세요.

결제했는데 앱을 올릴 수 없습니다

  • 본인 확인 · 기기 확인 · 전화번호 인증 세 가지가 모두 끝나야 합니다. Play Console 홈에서 남은 항목을 확인하세요.

Week 0 세션에서 같이 하는 것

온라인 1시간. 날짜는 사전 설문에서 받은 시간대를 모아 정하고 카톡방에 공지합니다.

1

개발자 계정 진행 상황 점검 ⭐

  • 신청하신 분 — 심사 상태 확인
  • 반려되신 분 — 원인 찾아서 같이 재제출
  • 아직 못 하신 분 — 그 자리에서 함께 진행
2

Claude Code 설치

  • VS Code 설치 · Claude Code 확장 설치 · 로그인
  • Claude 구독(Pro 이상)이 연결되는지 확인
  • 맥이든 윈도우든 상관없습니다. 화면만 조금 다릅니다
3

Node.js 설치

  • 2주차 앱 만들기에 필요합니다
  • Windows는 설치 중 PATH 체크를 놓치기 쉬우니 같이 확인합니다
4

계정 준비

  • GitHub 가입 — 3주차 배포에 씁니다
  • 공공데이터포털(data.go.kr) 가입 — 4주차에 씁니다
5

첫 대화 한 번

  • 폴더를 열고 Claude에게 말을 걸어봅니다. 1주차에 바로 들어갈 수 있게 감만 잡습니다

장비 관련 질문

맥을 씁니다. 괜찮나요?

  • 전혀 문제없습니다. 오히려 편한 조합입니다.
  • VS Code · Claude Code · Node.js · Expo 모두 동일하게 돌아갑니다. 앱 빌드는 클라우드가 하고, Play Console은 브라우저 작업이라 OS를 타지 않습니다.
  • 3주차 터미널·Git 부분은 맥이 조금 더 매끄럽습니다. Windows는 설치할 때 PATH 같은 잔손이 갑니다.

안드로이드 폰이 없습니다

  • 4주 과정을 끝까지 완주하실 수 있습니다. 딱 한 지점만 실물이 필요합니다.
  • 2주차 앱 실행 — PC 브라우저(웹 모드), 안드로이드 에뮬레이터, 아이폰·아이패드 어느 것으로도 됩니다. Expo Go는 iOS에도 있습니다.
  • 3주차 빌드·스토어 등록·업로드 — 폰 없이 전부 가능합니다. 클라우드 빌드와 브라우저 작업입니다.
  • 3주차 마지막 "스토어로 내 폰에 설치" — 여기만 실물 안드로이드를 권합니다. 지인 폰을 잠깐 빌리면 1분이면 끝납니다.

아이폰만 있습니다

  • 2주차는 그대로 하실 수 있습니다. Expo Go로 아이폰에서 앱이 실행됩니다.
  • 3주차도 스토어에 올리는 것까지는 똑같이 갑니다. 아이폰에 설치하는 것만 안 됩니다(플레이스토어가 없으므로).
  • 신청서에 아이폰만 쓰신다고 표시해 주셨으면 개인톡으로 미리 안내드립니다.

컴퓨터 사양이 낮습니다

  • 괜찮습니다. 무거운 작업인 앱 빌드는 클라우드가 대신 합니다.
  • Android Studio(10GB 이상)를 설치하지 않는 이유가 이것입니다.
