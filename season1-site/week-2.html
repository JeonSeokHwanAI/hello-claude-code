WEEK 02

Skill 만들기 — PRD로 빌드

이번 주는 설계 문서(PRD) 한 장을 보고 실제 동작하는 Skill을 직접 빌드하는 시간입니다. 예제는 강사가 실제로 쓰는 YouTube 탐색·분석 도구 한 쌍. "Claude가 PRD를 읽고 도구를 만든다"는 감각을 체득합니다.

날짜2026-05-27 (수)
시간21:00~ (기본 2h)
난이도입문~초급
선수 학습Week 1
제공 자료YouTube Tooling PRD

학습 목표

  • PRD(설계 문서)가 무엇이고 왜 Skill 제작의 출발점인지 한 문장으로 설명
  • PRD를 Claude에게 던져 Skill이 자동으로 빌드되는 과정을 직접 본다
  • youtube-explorer로 첫 검색 페이지를 띄우고, youtube-analyze로 영상을 요약한다
  • Skill의 내부 구조(SKILL.md · frontmatter · scripts)를 열어 본다

먼저 — Skill로 이런 것들이 됩니다 (짧은 시연)

본격적으로 만들기 전에, Skill이 어디까지 확장되는지 1~2분짜리 미니 데모로 훑어봅니다.

오늘 만들 것 — YouTube 도구 한 쌍

PRD YouTube Tooling 한 장에 두 스킬의 설계와 전체 소스가 들어 있습니다. 외부 SaaS 없이 내 컴퓨터에서 완결됩니다.

SKILL ①

youtube-explorer — 탐색

  • 키워드/채널 검색 → 카드 그리드 HTML 생성
  • 로컬 HTTP 서버 + Chrome 자동 오픈
  • 카드 클릭 → 모달 재생, "📝 분석 큐에 추가"
SKILL ②

youtube-analyze — 분석

  • URL/ID 또는 큐 → 자막 추출 → 마크다운 저장
  • Claude가 .md를 읽고 3줄 요약·키워드·논점 분석
  • (선택) 댓글까지 수집해 반응 패턴 분석
[explorer]                          [analyze]
키워드 → API → 필터 → HTML           URL/ID 또는 큐 → 자막 추출 → .md
   │                                    │
   └─ 뷰어에서 카드 클릭                └─ Claude가 .md 읽고 요약·키워드·논점
        │
        └─ "📝 분석 큐에 추가" ───────→ analyze-queue.jsonl
                                  ↑ 두 스킬을 잇는 단 한 줄의 계약

커리큘럼 구성

3교시 × 25분 — "PRD 이해 → 라이브 빌드 → 고도화·실습"

1ST · 25min · 이론

PRD란? 그리고 PRD → Skill 빌드 원리

  • Skill = AI 업무 매뉴얼 · PRD = 그 매뉴얼의 설계도
  • "바로 만들어줘" vs "PRD 보고 만들어줘" — 재현성의 차이
  • PRD §17 부트스트랩: 한 줄 요청으로 Claude가 전체 빌드하는 구조
  • Skill 폴더 구조 미리보기: SKILL.md + scripts/
2ND · 25min · 라이브 빌드

PRD 던지고 explorer 빌드 → 첫 검색

  • PRD 파일을 프로젝트에 두고 "이 PRD대로 youtube-explorer 빌드해줘"
  • Claude가 폴더·스크립트 생성 → 의존성 설치 → 스모크 테스트
  • .env에 YouTube API 키 넣기 (발급 안내 포함)
  • 첫 검색 실행 → Chrome에 카드 그리드 페이지 등장
3RD · 25min · 고도화·실습

analyze 추가 + 본인 키워드로 실습

  • 같은 PRD로 youtube-analyze 빌드
  • 큐에 담은 영상 → --next로 자막 요약 생성
  • 본인 관심 키워드/채널로 직접 탐색·분석
  • Skill 내부(SKILL.md)를 열어 "왜 이렇게 동작하나" 확인

PRD 기반 빌드 흐름 (한눈에)

이번 주 라이브에서 따라갈 단계입니다. 사용자가 PRD를 직접 읽을 필요는 없습니다 — Claude가 참고합니다.

① PRD 보고 skill 만들기      (초기 설치, 코드 생성)
② 유튜브 검색 페이지 만들기   (첫 사용 — explorer)
③ skill 고도화                (시청 기록 + 분석 큐)
④ 유튜브 분석 skill 만들기    (자막 분석 — analyze)
⑤ 댓글까지 분석하기           (반응 패턴)

강의 자료 다운로드

📦 YouTube Tooling PRD

  • 2주차에 Claude로 빌드할 두 스킬(explorer·analyze)의 설계 문서이자 전체 소스가 담긴 PRD입니다.
  • 내려받아 프로젝트 폴더에 두고, 강의 때 Claude에게 "이 PRD대로 빌드해줘"라고 던지면 됩니다.
  • 직접 다 읽을 필요는 없습니다 — Claude가 §17·§18을 참고합니다.
